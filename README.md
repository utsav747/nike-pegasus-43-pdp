# Nike Pegasus 43 product page

Mobile (375px) product page for the Nike Pegasus 43, built with Next.js (App Router), TypeScript and Tailwind CSS.

```bash
npm install
npm run dev   # http://localhost:3000, view in Chrome device mode at 375px
```

- `PROMPT.md`: the build prompt.
- `NOTES.md`: decisions, measured section heights, stock counts, deviations.
- Stock data: `data/pegasus-43-stock.json`.
- `PERFORMANCE-NOTES.md`: Slow 4G size grid check, speed limits and results.
